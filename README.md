# acm-app

Novo projeto ACM (multitenant). Substitui o uso do repositório `mendes-cruz-app` como base de trabalho.

## Estrutura

- `levantamento/` — Levantamento ACMAPP Multitenant: material enviado pelo Augusto, perguntas e as respostas de cada pessoa sobre como o sistema deve ficar.

## Como contribuir com o levantamento

1. Coloque o material original em `levantamento/material/`.
2. Responda as perguntas em `levantamento/respostas/<seu-nome>.md`.
3. Consolide a decisão final em `levantamento/DECISOES.md`.
